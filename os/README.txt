DCB OS PWA V1

This is the installable web-app version.

IMPORTANT:
A PWA must be served over HTTPS (or localhost) before Android will offer "Install app".
Opening index.html directly from Downloads is NOT the intended install path.

Once hosted:
1. Open the DCB OS URL in Chrome on Android.
2. Tap INSTALL if the button appears.
3. If it does not, Chrome menu > Add to Home screen / Install app.
4. DCB OS then opens from its own home-screen icon in standalone mode.

Included:
- real DCB before/after project photos
- swipe album
- finger/stylus drawing
- erase/clear
- before/after compare slider
- flipbook story playback
- save drawing locally
- offline cache after first successful load
- Android PWA manifest and icons
